# Product

## Platform

adaptive

## Purpose and scope

Private Angular Native test starter based on bhrenno2000/app-starter. Preserve the source login, session persistence, protected home, logout and light/dark/system theme flows in Portuguese. It is a developer template and a proof of concept, not a production authentication service.

## Existing design authority

The source repository supplies Inter fonts, blue brand palette, neutral light/dark semantic tokens, login form and home theme controls. Port these choices without inventing a new visual identity.

## Constraints

Angular Native is alpha. Native development builds are required for encrypted MMKV. Unit tests do not replace simulator or hardware verification. Local .claude instructions never enter the repository. Backend authorization and hardware validation remain necessary before production adoption.
